# mini-tools

个人开发的小型应用集合，每个应用在 `apps/` 下独立维护依赖、构建与运行配置。

| 应用 | 说明 | 平台 |
| --- | --- | --- |
| [To-Do](apps/to-do/) | 分组待办画布、日/月复盘、休息提醒 | Windows + Chrome / Edge |

## 仓库约定

- 新应用放入 `apps/<app-name>/`，不要复用其他应用的浏览器配置或数据目录。
- 提交源码、依赖锁文件及必要的静态资源；不提交运行数据、浏览器配置、个人备份、依赖目录、构建产物或测试报告。
- `.gitignore` 不能撤回已经提交的敏感内容，提交前仍需检查 `git diff --cached`。
- 不提交凭据或真实用户数据。需要示例数据时，应使用人工构造的测试数据。

当前 To-Do 为桌面版源码，不包含历史 HTML/移动版、个人记录或本机验收材料。字体授权见应用的 `public/fonts/`；项目代码暂未指定开源许可证。
